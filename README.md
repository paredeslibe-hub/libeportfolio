# Portfolio de Product Design

Sitio web inicial creado como punto de partida para el portfolio de Product Design.

## Archivos

- `index.html`: estructura principal de la página.
- `styles.css`: estilos responsivos y diseño base.
- `script.js`: comportamiento del menú móvil.

## Cómo usar

1. Abre `portfolio-website/index.html` en el navegador.
2. Reemplaza los textos y proyectos con el contenido real del portfolio.
3. Añade imágenes o assets en la carpeta `assets/` si es necesario.

## Próximos pasos

- Ajustar el estilo para que coincida con el diseño en Figma.
- Añadir imágenes reales, iconos y detalles de los proyectos.
- Conectar el formulario de contacto o integrar WhatsApp/Calendly si se desea.
